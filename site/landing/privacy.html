Trade Shortcuts Privacy Policy

Effective 26 November 2026.

This policy describes how Trade Shortcuts for Even G2 handles information on your phone, on the configured Trade Shortcuts server, and through optional services.

Connection and device settings

The Even Hub Beta app defaults to the hosted paper demo at https://ts-demo.31-77-204-20.sslip.io. Testers with separate access can connect to the private Bybit Testnet backend at https://ts-bybit.31-77-204-20.sslip.io. Self-managed builds connect to the server address set by the operator. The app stores the server address, access token and preferences such as gesture tips and voice answers in Even Hub storage, with browser local storage as a fallback. The app uses the token to authenticate requests to the configured server.

Trading data and history

The server evaluates the rules you set and handles positions, orders and fills. It stores shortcuts, preferences, alerts, trade proposals, execution history and audit events in its local database. On a simulated server, exchange data comes from the built-in demo. If an operator configures Bybit Demo Trading or Testnet, the server sends signed requests to Bybit and reads exchange data. Bybit API credentials stay in the server configuration.

G2 microphone and transcription

When the connected server has voice transcription configured and “Answer alerts by voice” is enabled, the G2 microphone can open for up to ten seconds when an actionable alert appears. After a spoken “yes,” it can listen again briefly for a cancellation during the countdown. The lens shows when it is listening. “Answer alerts by voice” defaults to on and can be turned off in Settings. The judge walkthrough uses touch controls with voice answers off.

Captured audio goes to the configured Trade Shortcuts server. The server forwards audio with speech to OpenAI for transcription and returns the interpreted response to the app. The Trade Shortcuts application does not save raw microphone recordings or transcription responses to its database. OpenAI handles data it receives under its own terms and data controls.

Retention and contact

Persistent server records stay in the server database until the operator removes them. For privacy questions or to request access to or deletion of data held by the hosted demo, contact astralex163@gmail.com. For a self-managed server, contact its operator.
